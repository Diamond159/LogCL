A. 项目概览
================================================================================

项目名称: LogCL (Local-Global History-aware Contrastive Learning for 
            Temporal Knowledge Graph Reasoning)
主要功能: 时态知识图谱推理,实现DSPN-CL双流预测网络

核心文件结构:
- src/main.py: 主入口,训练/测试流程控制
- src/rrgcn.py: 核心模型实现(RecurrentRGCN)
- src/decoder.py: 解码器(ConvTransE, ConvTransR)
- src/model.py: RGCN基类定义
- rgcn/utils.py: 工具函数,数据加载和处理
- rgcn/knowledge_graph.py: 知识图谱数据加载
- rgcn/layers.py: 图神经网络层实现

数据集: ICEWS14, ICEWS18, ICEWS05-15, GDELT
实验组织: experiments/目录下按论文表格组织实验

B. 明显错误
================================================================================

B1. 文件路径错误 - 已确认
- 文件: src/main.py:204
- 问题: 测试结果写入时,如果result目录不存在会报FileNotFoundError
- 代码:
  ```python

      with open(filename,'w', newline='') as f:
  ```
- 影响: 首次运行测试时会崩溃,无法生成结果文件

B2. 变量未定义错误 - 已确认
- 文件: src/main.py:639
- 问题: 使用了args.__dict__但args对象可能没有__dict__属性
- 代码:
  ```python
  args.__dict__["test_history_len"] = args.__dict__["train_history_len"]
  ```
- 影响: 可能导致运行时错误
- 修复建议: 使用args.test_history_len = args.train_history_len

C1. 数据泄漏风险 - 高度可疑
- 文件: src/main.py:152, src/main.py:382-383
- 问题: 测试阶段加载了训练阶段预计算的历史子图和索引字典
- 代码:
  ```python
  # Line 152: 测试时加载训练阶段的索引字典
  sr_to_sro = np.load('data/{}/his_dict/train_s_r.npy'.format(args.dataset), allow_pickle=True).item()
  
  # Line 382-383: 训练时加载预计算的历史子图

  ```
- 影响: 测试阶段使用了训练阶段的信息,可能导致评测结果偏高
- 证据等级: 可疑但证据不足(需要进一步验证测试时是否应该使用训练数据)

C2. 硬编码随机种子 - 已确认
- 文件: rgcn/knowledge_graph.py:21
- 问题: 数据加载时固定了随机种子
- 代码:

- 影响: 影响实验的可重复性和随机性,可能导致结果偏差
- 修复建议: 将随机种子作为参数传入,或移除固定种子

C3. 训练测试数据混用 - 可疑
- 文件: src/main.py:348-349, src/main.py:461-462
- 问题: 测试时使用了train_list+valid_list作为历史输入
- 代码:
  ```python
  # Line 348-349: 测试函数调用
  test(model, args.train_history_len, train_list+valid_list, test_list, ...)
  
  # Line 461-462: 训练后测试

  ```
- 影响: 测试时使用了训练和验证数据作为历史,可能导致数据泄漏
- 证据等级: 可疑但需要确认时序推理的标准做法

C4. 历史子图采样逻辑不一致 - 可疑
